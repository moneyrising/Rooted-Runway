🔄 Need a fresh start?
This tool saves your numbers automatically in your browser. To clear everything and start over:
Chrome / Edge: Press F12 → Console tab → type localStorage.clear() then press Enter → refresh the page.
Safari: Settings → Advanced → Show Web Inspector → Console tab → same command above.
Easiest option: Open the tool in a private / incognito window for a clean session every time.
